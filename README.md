A single original line roasting a gadget used every day, entered in the
[make.fun bounty](https://make.fun/c/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610):

> My earbuds disconnect mid-sentence, then reconnect just to announce that they disconnected.

## Run

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line plus one trailing
newline to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to
`/output/entry.txt`. The write is validated (one non-blank line, 1–200
characters) and atomic.
